# Power BI Sales Analytics Dashboard

## Project Overview

This project is an interactive **Sales Analytics Dashboard** created using Microsoft Power BI. It provides visual insights into sales performance, trends, categories, regions, and key business metrics.

## Tools Used

* Microsoft Power BI
* Power Query
* DAX
* Excel

## Dashboard Features

* KPI cards
* Sales performance analysis
* Category-wise analysis
* Region-wise analysis
* Sales trend analysis
* Interactive filters and slicers
* Data visualizations

## Objective

The objective of this project is to analyze sales data and convert it into meaningful visual insights that can help understand business performance.

## Project Files

* `.pbix` – Power BI dashboard
* `.xlsx` – Source dataset
* `.png` – Dashboard preview
